## Quick Start

```sh
docker run -p 3000:3000 -v ./data:/app/data pregnancy1000/assetmanagment:latest
```

Open [http://localhost:3000](http://localhost:3000), then add assets, upload photos and receipts, and track warranties or maintenance events.

For the full English guide, see [README.en.md](README.en.md).
